# 합덕제철고등학교 학교생활 페이지

오늘의 급식, 선택한 학급의 오늘·주간 시간표, 이번 달 학사일정을 그리드로 보여 주는 정적 GitHub Pages 사이트입니다. 자료는 NEIS 오픈 API의 `mealServiceDietInfo`, `hisTimetable`, `SchoolSchedule` 서비스를 GitHub Actions에서 가져옵니다. API 키는 브라우저에 전달되지 않습니다.

## GitHub Pages 설정

1. 저장소의 **Settings → Secrets and variables → Actions**에서 `NEIS_API_KEY` 이름의 Actions secret을 설정합니다. 키를 HTML, JavaScript, JSON, 커밋 또는 공개 로그에 넣지 마세요.
2. **Settings → Pages → Build and deployment**에서 **GitHub Actions**를 선택합니다.
3. `main`에 변경 사항을 푸시하거나 Actions의 **Publish school portal** 워크플로를 수동 실행합니다. 워크플로는 평일 22:00 UTC(한국 시간 다음 날 07:00)에 데이터를 새로 받아 게시합니다.

Actions 실행이 성공하면 `data/neis.json`을 생성해 사이트와 함께 배포합니다. 이 파일의 저장소 내 기본 내용은 로컬 미리보기용 대기 상태이며, 실제 급식이나 시간표를 나타내지 않습니다.

## 데이터 및 시간표 안내

- 학교 코드는 `schoolInfo`에서 학교 이름이 정확히 일치하는 결과를 찾아 사용합니다. 학교 조회 결과가 없거나 여러 개면 게시 작업이 실패하도록 했습니다.
- 매주 월요일부터 금요일까지 급식 및 고등학교 시간표 API를 요청합니다. 시간표는 학년·반 구분 없이 받아 브라우저에서 선택한 반만 표시합니다.
- `SchoolSchedule` API에서 이번 달 학사일정을 함께 가져와 오늘 이후의 일정을 표시합니다.
- NEIS가 알려 준 전체 건수만큼 시간표 자료를 가져오지 못하거나 페이지가 반복되면 업데이트가 실패합니다. 불완전한 시간표를 정상 데이터처럼 게시하지 않습니다.
- NEIS에 선택한 반의 이번 주 자료가 없으면 페이지는 누락 상태를 분명히 알리고, 학교에서 제공하는 수동 시간표 데이터가 필요할 수 있다고 안내합니다. 시간표를 만들어 내거나 정상 자료인 것처럼 표시하지 않습니다.
- 2학년은 요청에 따라 모든 반 선택에서 화요일 5~6교시와 수요일 1~6교시를 `코스`, 목요일 1~4교시를 `선택과목`으로 표시합니다. 이는 화면의 표시 규칙이며, NEIS 원본 과목이나 공식 시간표를 뜻하지 않습니다.
- 3학년은 모든 반에서 월요일 2~4·6~7교시를 `코스`, 화요일 1~4교시를 `선택과목`으로 표시하고, 금요일 1~4교시는 5반을 제외한 반에서 `선택과목B`로 표시합니다. 이는 화면의 표시 규칙이며, NEIS 원본 과목이나 공식 시간표를 뜻하지 않습니다.
- 학교가 NEIS에 시간표를 제공하지 않는 경우 이 사이트에는 수동 시간표 입력 기능이 없습니다. 학교에서 별도로 제공하는 데이터를 연결해야 합니다.
- `NEIS_API_KEY`가 브라우저 코드나 로그에 노출된 적이 있다면 해당 키를 재발급하고 저장소 secret을 교체하세요.

## 로컬 미리보기

정적 파일을 웹 서버로 제공한 뒤 페이지를 엽니다. API 조회는 `NEIS_API_KEY`가 있는 Actions에서만 수행합니다. 로컬 미리보기에서는 실제 데이터 생성 전까지 준비 상태가 표시됩니다.

## 웹 개발 에이전트

`.github/agents/web-developer.agent.md`에 프로젝트 전용 **hab 웹 개발** 에이전트가 있습니다. 저장소의 커스텀 에이전트를 지원하는 Copilot 환경에서 해당 이름을 선택하고 작업을 요청합니다.

급식·시간표·학사일정 화면, 학급 선택 저장, 모바일 대응과 접근성 구현을 담당하며, NEIS 키 보호와 실제 데이터 검증 원칙을 따릅니다. Hallmark는 별도 설치된 경우에만 활용합니다. GitHub 원격 저장소에서도 사용하려면 이 에이전트 파일을 해당 저장소에 반영해야 합니다.

## 데이터 검토 에이전트

`.github/agents/data-reviewer.agent.md`의 **hab 데이터 검토**는 읽기 전용 에이전트입니다. 학교·학급 일치, 한국 시간 기준 날짜·최신성, NEIS 페이지 누락·반복·중복, 데이터 매핑과 키 노출 경로를 살펴보고 근거와 수정 권고를 보고합니다. 코드 수정, 명령 실행과 배포는 하지 않습니다.

예를 들어 “이번 주 급식·시간표 데이터의 누락과 날짜 처리를 검토해줘”라고 요청합니다. 인증된 API 응답 등 접근할 수 없는 자료는 미확인으로 구분하며, 확인된 문제의 수정은 웹 개발 에이전트에 맡깁니다.
